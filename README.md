# **React and Express To-Do App**



###### **Introduction**



This is a simple full-stack To-Do application built using React for the frontend and Express.js for the backend. It allows users to add, view, update, and delete tasks.



###### **Technologies Used**



* React.js
* Node.js
* Express.js
* Axios
* CORS
* JavaScript



###### **Features**



* Display all To-Do tasks.
* Add new tasks.
* Prevent duplicate tasks.
* Mark tasks as completed.
* Delete tasks.
* Handle errors using HTTP status codes.



###### **How to Run the Project**



1\. **Start the Backend**



Open CMD and navigate to the backend folder:



cd Desktop/fullstack-react-express/backend

npm install

node server.js



The backend runs at:



http://localhost:5000



2\. **Start the Frontend**



Open a second CMD window and enter:



cd Desktop/fullstack-react-express/frontend

npm install

npm start



The frontend runs at:



http://localhost:3000



###### **API Routes**



**GET**: View tasks

**POST**: Add tasks

**PUT**: Update tasks

**DELETE**: Delete tasks



###### **Learning Outcome**



Through this project, I learned how to create an Express server, build REST API routes, connect React with a backend using Axios, perform CRUD operations, and handle errors using HTTP status codes.
